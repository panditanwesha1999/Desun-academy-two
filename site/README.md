# Desun Academy homepage

## Preview (important)
Do NOT open index.html by double-clicking. YouTube refuses to play embedded videos from a local file (Error 153).
Run `preview.bat` (Windows, needs Python) or `python -m http.server 8000` inside the site folder, then open http://localhost:8000.

## You must supply
- assets/video/hero-reel.mp4 : the Instagram reel as an mp4. Instagram cannot be embedded with muted autoplay. Without this file the hero shows a still poster. Both hero videos use this one file.
- assets/img/story-2.jpg, story-3.jpg : real photos of Rahul Shaw and Sourav Biswas (current ones are temporary crops from testimonial thumbnails).
- Better originals for podcast thumbnails and certificates.

## Placeholders (search "PLACEHOLDER" in index.html / script.js)
- Stats, mentor roles, program data other than UI/UX, story copy, social links, Blog and Winter Contest links.
- js/script.js CONFIG: FORM_ENDPOINT (empty = demo mode, the form sends nothing), CONTACT.
